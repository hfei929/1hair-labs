## 本地运行

安装依赖：

```bash
pip install mkdocs-material
```

启动开发环境：

```bash
mkdocs serve
```

访问：

```text
http://127.0.0.1:8000
```

---

## 构建站点

```bash
mkdocs build
```

生成目录：

```text
site/
```
