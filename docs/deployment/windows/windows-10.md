# Windows 10 部署教程

本教程面向新手，详细说明从准备安装介质到完成系统初始配置的完整流程。本文以虚拟机和物理机通用的安装步骤为主，图片位置可在虚拟机中截图补充。

## 1. 部署前的准备

1. 选择正确的 Windows 10 版本
     - 家庭版（Home）：适合个人日常使用(老实说我个人并不推荐使用)。
     - 专业版（Pro）：适合需要远程桌面、组策略、安全功能的用户。
     - 企业版（Enterprise）：适合公司内部大规模部署。

2. 安装介质准备
     - 官方 ISO：建议从微软官网或授权渠道下载 Windows 10 安装 ISO；想立即下载安装，点击下面的链接：
         - [夸克网盘](https://pan.quark.cn/s/0c41503a4c4d?pwd=YTij)
         - [迅雷](ed2k://|file|zh-cn_windows_10_consumer_editions_version_22h2_updated_oct_2025_x64_dvd_38efd00d.iso|7168839680|C16CA4505649F9128F6F42A1DE2D7526|/)
     - 虚拟机环境：如果在 VMware、VirtualBox、Hyper-V 或 Proxmox 等虚拟机中安装，直接挂载 ISO 即可。
     - 物理机安装：需要制作启动 U 盘。推荐使用 [Rufus](https://rufus.ie/) 、[Ventoy](https://www.ventoy.net/cn/index.html) 或微软官方媒体创建工具。

3. 系统资源和硬件要求

    - CPU：1 GHz 或更快，支持 PAE、NX 和 SSE2。
    - 内存：最低 4 GB，推荐 8 GB 及以上。
    - 存储：最低 64 GB，可用空间建议 120 GB。
    - 显卡、网络、磁盘控制器：确保虚拟机中已加载对应驱动，或物理机驱动兼容。

4. 虚拟机与硬盘方案
    - 推荐先在虚拟机中模拟安装流程，确认设置正确。
    - 物理机安装前请备份现有数据。

## 2. 启动安装介质

1. 启动虚拟机或物理机并进入 BIOS/UEFI
    - 物理机：一般按 `F1`、`F2`、`Del`、`F12`、`Esc` 等进入固件设置。
    - 虚拟机：检查 VM 设置是否选择从光驱或 ISO 启动。

2. 设置启动顺序
    - 物理机：将 U 盘或 DVD 设置为首选启动项。
    - 虚拟机：将 ISO 挂载到虚拟光驱，并启用“从 CD/DVD 启动”。

3. 兼容模式选择
    - 新主板建议启用 UEFI+GPT 模式。
    - 老旧机型可选择 Legacy BIOS + MBR 模式。
    - 更多原理见：[#UEFI 与 GPT](#uefi-gpt)

## 3. 开始安装 Windows 10

1. 进入安装界面
    - 启动后出现“Windows 安装程序”，选择语言、时间和键盘布局。
    - 点击“下一步”，再点击“现在安装”。

2. 输入产品密钥
    - 有密钥：直接输入。
    - 没有密钥：点击“我没有产品密钥”，先选择版本后安装完成后再激活。

3. 接受许可条款
    - 勾选“我接受许可条款”，然后继续。

4. 选择安装类型
    - “自定义：仅安装 Windows（高级）”：适合全新安装。
    - “升级”：仅用于已有 Windows 系统升级，不建议新手用于全新部署。

## 4. 磁盘分区与格式化

1. 选择目标磁盘
    - 在“你想在哪里安装 Windows？”页面，选择一个空磁盘或已有分区。
    - 若磁盘有旧分区，建议先删除所有的旧分区，创建新的安装分区。

2. 创建分区
    - 直接点击“新建”，系统会自动创建必要的 EFI 系统分区、MSR 分区等。
    - 如果需要自定义分区方案，可以先创建一个主分区用于系统盘，再创建数据盘。

3. 格式化分区
    - 选中目标分区点击“格式化”。
    - 若是新磁盘，安装程序会自动格式化。
    - 更多细节见：[#磁盘分区与文件系统](#disk-partitioning)

4. 开始复制文件
    - 选择合适的分区后，点击“下一步”。
    - 安装程序将复制文件、展开 Windows 文件、安装功能和更新。
    - 过程可能需要 15-30 分钟，期间虚拟机可能自动重启几次。

!!! tip "简便方法"
    这一步选择的的磁盘如果有旧分区，直接删除所有的旧分区，然后直接 `下一步`；没有的话直接选择你需要安装的目标磁盘直接 `下一步` 即可。理由：如果磁盘空间不够富裕，没必要单独分多个区，直接使用一个磁盘当作 C盘。如果磁盘空间足够富裕，也没有必要分多个区，直接使用一个磁盘作为一个分区。

## 5. 初始设置

1. 选择区域和键盘布局

    - 根据实际使用地区选择“区域”和“键盘布局”。
    - 可在后续设置中添加其他语言和输入法。

2. 连接网络
    - 推荐先连接网络，便于后续下载更新。
    - 虚拟机若无法联网，可先跳过，安装完成后再配置网络。

3. 登录账户
    - 本地账户：选择“离线账户”或“脱机账户”，适合不想绑定 Microsoft 账户的用户。
    - Microsoft 账户：推荐用于云同步、OneDrive、应用商店等功能。

4. 隐私设置和功能体验
    - 可根据需求关闭“位置”、“语音激活”、“广告 ID”等隐私选项。
    - 也可先按推荐设置，后续再逐项调整。

## 6. 完成安装后的检查与配置

1. 登录桌面后检查驱动程序
    - 进入“设备管理器”，查看是否有未识别设备或黄色叹号。
    - 虚拟机环境：建议安装 VMware Tools、VirtualBox Guest Additions、Hyper-V 集成服务或类似增强工具。
    - 物理机：安装主板芯片组、显卡、网卡、声卡驱动。
    - 详情见：[#驱动安装与设备管理](#driver-management)

2. 安装 Windows 更新
    - 打开“设置 > 更新和安全 > Windows 更新”，点击“检查更新”。
    - 安装所有重要更新、驱动程序更新和累积更新。

3. 配置磁盘与存储空间
    - 如果安装时只划分了一个磁盘，可在“磁盘管理”中创建额外数据分区。
    - 需要时启用 BitLocker 磁盘加密（Enterprise/Pro 可用）。

4. 配置网络与共享
    - 确保网络类型设置为“私人网络”或“公用网络”，根据环境选择。
    - 配置文件共享、远程桌面、网络发现等功能。
    - 更多内容见：[#网络配置与防火墙](#network-configuration)

5. 创建恢复点与备份
    - 建议完成系统安装后立即创建恢复点。
    - 如果是重要环境，可使用系统镜像或第三方备份工具。
    - 更多说明见：[#系统备份与还原](#system-backup-and-restore)

## 7. 常见问题及优化建议

1. 安装过程中出现“找不到驱动器”
    - 可能是因为缺少 SATA/NVMe 控制器驱动，虚拟机需检查磁盘控制器模式。
    - 物理机可在 BIOS 中切换 AHCI/RAID 模式，或下载主板驱动。

2. 安装完成黑屏或分辨率异常
    - 可能是显卡驱动问题，先进入安全模式安装正确驱动。
    - 虚拟机则应安装增强工具以获得完整显示支持。

3. 无法联网
    - 检查虚拟网卡是否启用，或物理机网线、Wi-Fi 是否正常连接。
    - 检查网络适配器驱动并确保 DHCP / IP 设置正确。

4. 系统激活问题
    - 先检查产品密钥是否正确，对应版本是否一致。
    - 若无法在线激活，可尝试电话激活或联系官方支持。

## 8. 其他建议

- 安装完成后建议立即更新 Windows 10 到最新版本，保障系统安全。
- 对于虚拟机，建议快照或克隆虚拟机镜像，方便回滚。
- 如果计划长期使用该系统，可安装常用软件、杀毒软件、压缩工具、浏览器并配置默认应用。
