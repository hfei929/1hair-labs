# Linux

> Linux 不只是一个操作系统，它是现代基础设施的底座。

无论是 Kubernetes、Docker、数据库、中间件、虚拟化平台还是云计算环境，其底层几乎都运行在 Linux 之上。

对于运维工程师、SRE 和平台工程师而言：

> 理解 Linux，才能真正理解现代基础设施。

本专题记录工作与实验过程中涉及的 Linux 知识、运维经验以及故障实践，希望帮助读者从「会使用 Linux」逐步走向「理解 Linux」。

---

## 为什么学习 Linux？

今天的大部分基础设施都建立在 Linux 之上：

- Kubernetes 节点运行 Linux
- Docker 基于 Linux 内核能力实现
- 云服务器绝大多数采用 Linux
- 数据库、中间件广泛部署于 Linux
- Prometheus、Grafana 等监控系统运行于 Linux
- OpenStack、Ceph 等基础设施依赖 Linux

如果说：

```text
Kubernetes 是云原生的大脑，
那么 Linux 就是整个基础设施的地基。
```
