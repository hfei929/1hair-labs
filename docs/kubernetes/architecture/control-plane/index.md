# Control Plane 专题

控制平面负责维护 Kubernetes 的“期望状态”，是集群的大脑。这里归档了 API Server、Scheduler、Controller Manager 与 etcd 的核心原理文章。

## 主题范围

- API Server：集群唯一入口
- Scheduler：Pod 调度决策
- Controller Manager：控制回路与状态协调
- etcd：集群状态存储与一致性
