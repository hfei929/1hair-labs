# Kubernetes

> 从实验环境到生产集群，记录 Kubernetes 的学习、实践与故障处理过程。

Kubernetes 是当前云原生领域最重要的基础设施平台之一，也是现代平台工程的重要组成部分。

本专题主要围绕以下方向展开：

* Kubernetes 集群部署
* 高可用架构设计
* Ingress 与流量管理
* 存储系统与 CSI
* Pod 网络模型
* 集群升级与运维
* 故障排查与恢复
* 生产环境最佳实践

## 推荐阅读

* Kubernetes 高可用集群实践
* Ingress 工作原理解析
* Kubernetes 网络流量全链路
* ETCD 恢复演练
